Velox 1.1.0 是一次底子上的重做：界面换成全新的设计体系，首次渲染体积砍掉约三分之二，在 Velox 之外改动过的文档会自动跟进。

## 亮点

- **全新视觉体系**：不再靠描边和蓝灰配色区分层次，改用 1–3% 的明度差；单一强调色、1.25 模数标题阶梯、68ch 阅读宽度。暗色模式把每个字重下调 40，白字不再显粗；焦点态改为双环而不是外描边。
- **首次渲染轻了 67%**：3.0 MB → 991 KB（gzip 151 KB）。Markdown 解析（remark / rehype / KaTeX）移入 Web Worker，代码高亮换成按需加载的单个 shiki 实例，Semi UI（1.14 MB JS + 777 KB CSS）由自建组件库替代。
- **外部改动自动同步**：在别的编辑器里改同一个文件，无未保存内容时静默刷新并保留光标；有冲突时弹出内联提示而不是覆盖。窗口重新获得焦点时还会复核网络盘上的文件。
- **窗口即刻出现**：窗口先于 SQLite 与服务创建，`index.html` 自带主题骨架，启动时不再有白屏方块。实测窗口出现约 230–350 ms，首帧可交互约 0.6–1.1 s。

## 其它改进

- 资源管理器开关移到标题栏最左侧，紧邻它控制的侧栏，不再挤在「源码 / 预览」切换按钮旁。
- 标签拖拽落位改用过阻尼弹簧曲线；搜索替换行展开不再计算高度。
- `MainLayout` 拆成纯函数、组件与 hooks（约 2,600 行 → 1,480 行）。
- 从命令行或文件关联打开 Markdown 时，不再先被欢迎页覆盖。
- 代码块「已复制」提示 2.5 s 后自动收起，不再残留对勾与重复提示。
- 仓库新增四道守卫：`lint:design`、`check:bundle`、`test:markdown`、`test:visual`。

## 升级说明

- 现有工作区、偏好设置与文档原样保留，可直接覆盖安装，或交给内置更新器自动升级（三个平台都已发布 `latest*.yml` 更新元数据）。
- Windows 提供 x64 安装包；macOS 提供 x64 / arm64 的 dmg 与 zip（CI 未做签名与公证，首次打开需右键 → 打开）；Linux 提供 x86_64 AppImage 与 amd64 deb。
